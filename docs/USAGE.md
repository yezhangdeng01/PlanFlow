# PlanFlow 使用说明

> PlanFlow 是一个基于 Obsidian 的计划系统插件：

- **计划自动拆解+每日打卡行动：让目标细化成可执行的颗粒**
- **清晰目标追踪：四个页面一条闭环，今日行动 / 计划管理 / 任务看板 / 我的成就**
- **自动统计激励系统：打卡连续天数 + 铜银金徽章 + 成就墙**
- **数据自动流转：统一数据源，纯 Markdown，告别杂乱**

---

## 一、设计理念

### 1. 计划是一条流，不是一堆表

大多数计划工具把「年度目标、月度计划、每日打卡」做成互不相通的三套数据，靠手动同步。PlanFlow 则实现计划自动拆解、数据统一互通，让计划和执行都更简单：

![](screenshots/flow.png)

- **数据只产生一次**：年度计划定义在 `年度计划.md` 的 frontmatter，任务写在任务池，打卡勾选写回每日笔记——**没有重复录入**。
- **全视图聚合追踪**：今日/计划/看板/成就的进度与统计，全部由日期窗口自动聚合，**零配置**。
- **日期窗口自动归属**：任务标上起止日期，本周 = ISO 周、本月 = 自然月、当年 = 当前年份——不需要手动建立任何父子关系，也不会断链。

### 2. 执行优先

「今日打卡 + 今日总结」是界面的视觉中心，年度目标进度条常驻顶部——打开 Obsidian 第一眼看到的是「今天要做什么、做了多少」。

![](screenshots/today-action.png)

### 3. 数据属于你

所有数据是普通 Markdown 文件（frontmatter + 任务列表 + 标签），随时可读、可迁移、可备份，插件停用数据完好。

## 二、功能性

### 四个页面，一条闭环

| 页面 | 职责 | 核心操作 |
|---|---|---|
| **今日行动** | 目标 → 执行 → 总结 | 勾选打卡、日期下拉补昨日卡、写今日总结、一键写复盘 |
| **计划管理** | 计划总览与目标管理 | 新建计划自动生成每日行动打卡，量化目标自动拆解到月/周任务 |
| **任务看板** | 执行面板（分类 / 状态 / 甘特三形态） | 按计划分组、列头拖拽调宽、甘特拖拽调期 |
| **我的成就** | 统计与激励 | 徽章墙、打卡统计环、月度分布、累计曲线、热力图 |

### 今日行动

![](screenshots/today-action.png)

- **年度目标条**：各计划进度一目了然，进度条随打卡自动前进
- **今日打卡**：行末「打卡」按钮一点即完成；日期下拉选「昨天」可以补卡
- **今日总结**：✅ 已完成统计 + 鼓励语实时更新，手动撰写双通道互不覆盖
- **本月每日打卡**：整月柱状图 + 🔥 连续打卡天数（当天完成 ≥1 项就算一天）
- **本月各计划打卡 / 周·月任务清单**：按计划聚合，完成情况一屏总览

### 计划管理

![](screenshots/plans.png)

- **打卡行动**：每个计划的打卡进度条（N/总天数），标题行 ✏️ 打开「管理打卡项」——列表逐项删、跨日期补录、新增手动打卡项
- **量化目标**：目标进度条（如「公众号文章 1/8 篇」）自动统计，✏️ 编辑目标即增删任务
- **任务列表**：量化目标自动拆解出的周期任务，勾选即完成
- **新建 / 编辑 / 删除**：「＋ 新增计划」建计划；卡头右键或 ✏️🗑️ 管理，删除计划连带清理其打卡项

### 任务看板

![](screenshots/tasks.png)

- **三种形态**：分类（按计划分列）/ 状态（按完成情况）/ 甘特（时间轴），一排切换
- **分类看板**：列 = 计划，列头拖拽调宽
- **甘特**：整年 12 个月刻度，拖拽条形调期、直观看重叠
- **顶部过滤**：按年份与计划分组过滤，右上角显示任务总数

### 我的成就

![](screenshots/achievements.png)

- **徽章墙**：周/月完成度自动结算铜/银/金徽章，累计计数
- **年度任务**：年度完成度环形图，按计划分色
- **打卡统计**：各计划打卡次数环形图（N/144 天窗口 + 完成率）
- **月度打卡分布 / 累计打卡曲线 / 打卡热力图**：全年节奏一图看清

## 三、易用性

### 快速上手（3 步）

1. **建年度计划**：计划管理页「＋ 新增计划」，会自动创建相关每日行动打卡；

2. **建量化目标**：在计划卡里添加量化目标，会自动拆解成周期任务；

3. **打卡**：今日行动勾选即完成，进度自动聚合到看板与成就页。

### 常用交互速查

| 想做什么 | 怎么做 |
|---|---|
| 新建计划 | 计划管理页「＋ 新增计划」 |
| 添加量化目标 | 计划卡「🎯 量化目标」区 → ✏️ 编辑表单添加 |
| 管理今日打卡项 | 计划卡「✅ 打卡行动」标题行 ✏️ |
| 补昨天的卡 | 今日打卡行日期下拉选「昨天」再打卡 |
| 删除某个打卡项 | 「✅ 打卡行动」✏️ → 管理弹窗内删除（可撤销）；自动生成的项随计划删除 |
| 调整计划顺序 | 计划管理页拖卡头 |
| 调整卡片高度 | 拖卡下边缘把手 |
| 编辑/删除计划 | 计划卡头**右键**或 ✏️🗑️ |
| 写复盘 | 今日总结卡「写复盘 →」 |
| 自定义打卡项模板 | 设置页配置每日打卡模板 |

### 说明

- 界面为中文；数据字段（frontmatter/标签）保持英文
- 纯本地运行：无网络调用、无遥测、数据不出 vault
